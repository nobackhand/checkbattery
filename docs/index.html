Features

  • Always on top Floats above all windows. Auto-hides in fullscreen apps.
  • Time, not percent Shows hours and minutes remaining so you know when to plug in.
  • Hover popup Charge rate, capacity, wear level, ETA, and a 2-hour sparkline.
  • DPI aware Renders crisp on any display scaling. No blurry text.
  • Customizable Dark/light/auto theme. 8 accent colors. 3 pill sizes.
  • Portable Single .exe, no installer, no dependencies. Config saved locally.

Install

  1. Download BatteryPill-1.0.0.exe from the button above
  2. Double-click to run. The pill appears on your desktop.
  3. Drag it wherever you want. Right-click the tray icon for settings.
